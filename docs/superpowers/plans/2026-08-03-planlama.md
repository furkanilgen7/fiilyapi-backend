Her task = tek subagent + commit · TDD · DB komutları HEP override'lı · **ARA REVIEW YOK** (WORKFLOW §2).

## T1 — Migration + modeller
- `site_plan_rows` + `site_plan_cells` + `site_plan_goals` (+S4: `site_plan_sprints`) + 3 enum.
- İzin migration'ı GEREKMEZ (S1: `site_diary` kullanılır). upgrade→downgrade→upgrade; `DROP TYPE`'lar.

## T2 — Okuma ucu (TDD)
- `GET /sites/{id}/plan?week_start=` — bölüm gruplu satırlar + hafta hücreleri + hedefler + sprint.
- `week_start` Pzt'ye normalize edilir (değilse 422). IDOR + izin (PM view) testleri.

## T3 — Yazma uçları (TDD)
- `PUT rows` (DEĞİŞTİRME; silinen satırın hücreleri CASCADE — test) · `PUT cells?week_start=`
  (DEĞİŞTİRME; **kapsam kanıtı: başka haftanın/başka şantiyenin hücresine dokunulmaz** — PT deseni;
  FOR UPDATE) · `PUT goals?week_start=` (DEĞİŞTİRME) · (S4) `PUT sprint`.
- Saha müh. yazabilir, PM yazamaz (izin testleri). Audit: uç başına dönem-özetli tek olay.

## T4 — Gün özeti ucu (S2 onaylıysa, TDD)
- `GET /sites/{id}/plan/day-summary?start=&days=` — F-SD'nin GK gömülü bloğu için salt-okunur türev
  (gün başına hücre metin birleşimi + crew işçi toplamı + bölüm etiketleri + "plan yok" günleri).

## T5 — Kapanış + FINAL REVIEW (Opus)
- Tüm paket + ruff (tüm repo) + `alembic check` temiz + migration turu.
- openapi üret → DEVİR KURALI (WORKFLOW §4): frontend checkout main'de+temiz değilse KOPYALAMA, rapor;
  temizse kopyala + not (`gen:api` frontend main'inde tek commit; BFF `sites` kökü ZATEN listede —
  plan uçları `/sites/...` altında, yeni kök GEREKMEZ, nota yaz).
- Review odağı: IDOR · PUT kapsam sınırları · CASCADE davranışı · kalıcı karar taraması (malzeme/
  ekipman-FK/plan-gerçekleşen sızıntısı yok). `ARCHITECTURE-BACKEND.md` + `ROADMAP-BACKEND.md`
  güncellenir, commit. Push/PR/merge/deploy kullanıcıda.
